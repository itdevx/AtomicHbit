# ⚛️ Atomic Habit

پلتفرم ساخت **عادت**، **تمرکز** و **پاسخ‌گویی اجتماعی** بر اساس اصول روانشناسی رفتاری (هویت، شروع کوچک، اثر مرکب، حلقهٔ عادت).

> مناسب برای رزومه، تمرین Node.js و دموی محصول شخصی.

---

## ✨ قابلیت‌ها

### عادت و تسک
- ساخت، ویرایش و حذف عادت
- فیلدهای رفتاری: نشانه (Cue)، نیت اجرایی، نسخهٔ ۲ دقیقه، رأی هویت
- چک‌لیست روزانه با تیک آنی
- **Streak** (زنجیرهٔ روزهای متوالی)
- تسک روزانه جدا از عادت‌ها
- آمار تسک **هفتگی / ماهانه / سالانه**

### داشبورد و پیشرفت
- درصد پیشرفت امروز
- نمودار میله‌ای ۷ روز (Chart.js)
- نقشهٔ حرارتی ماه (تقویم جلالی — ۲۹/۳۰/۳۱ روز)
- **مزرعهٔ پیشرفت** (بذر → جوانه → نهال → درخت → مزرعه) با XP و سطح
- جملهٔ هویت شخصی
- به‌روزرسانی آمار به‌صورت نزدیک به realtime

### تایمر تمرکز
- تایمر ۱۵ تا ۶۰ دقیقه (و قابل تنظیم)
- دسته‌بندی: تمرکز / مطالعه / کار
- با ترک تب، تایمر متوقف می‌شود و قابل ادامه است
- ثبت دقایق روی پروفایل

### تمرکز دونفره
- آیدی عددی یکتا برای هر کاربر
- جستجوی realtime با آیدی
- دعوت، قبول، تایمر **مشترک**
- هر دو باید «شروع مشترک» بزنند
- ترک تب توسط یک نفر → توقف برای هر دو (زمان حفظ می‌شود، ریست نمی‌شود)
- چت خصوصی داخل اتاق
- لیست جلسات فعال و تاریخچه اتاق‌ها
- دسترسی فقط برای دو عضو اتاق (امنیت)

### اجتماعی
- **فالو / آنفالو** با شمارندهٔ دنبال‌کننده و دنبال‌شونده
- **گروه**: ساخت، درخواست عضویت، تأیید سازنده
- جداسازی «گروه‌های من» و «سایر گروه‌ها»
- مشاهدهٔ اعضای گروه
- **لیدربورد** بر اساس XP و بج تمرکز
- **اعلان‌ها** (ذخیره‌شده + realtime)
- نوتیف ریپلای چت → کلیک → رفتن به همان پیام

### چت
- چت گروه و چت دونفره (بدون چت عمومی)
- ظاهر شبیه پیام‌رسان: حباب، ساعت، **پاسخ (Reply)**
- پنل **ایموجی**
- دکمه ارسال
- در حالت گروه: چت تمام‌صفحه و چسبیده به پایین (مثل تلگرام)

### پروفایل و تاریخچه
- پروفایل عمومی با ساعات مطالعه/کار/تمرکز
- بج‌های تمرکز (چوبی تا افسانه‌ای) جدا از مزرعه
- تاریخچه فعالیت‌ها با امکان حذف تکی یا همه

### تقویم و زمان
- ساعت ایران **realtime** (هر ثانیه، بدون ریلود)
- منطق تاریخ لاگ بر اساس منطقهٔ زمانی تهران / جلالی

### احراز هویت
- ثبت‌نام با ایمیل و نام کاربری **یکتا**
- ورود با ایمیل یا نام کاربری
- آماده‌سازی ورود با **Google OAuth** (با تنظیم env)

### UI / UX
- تم دارک سرمه‌ای با اکسنت نیلی–سبز
- هدر ریسپانسیو + منوی همبرگری در موبایل
- نوار پایین (Bottom Nav) در موبایل
- پدینگ ایمن از لبه‌ها (safe-area)
- فونت Vazirmatn (RTL)

### امنیت
- دسترسی محدود به اتاق دونفره و چت گروه
- بررسی دسترسی در HTTP و Socket.IO
- هدرهای امنیتی پایه (`X-Frame-Options`, `nosniff`, …)
- محدودیت نرخ درخواست روی لاگین/ثبت‌نام
- هش رمز با bcrypt
- سشن HttpOnly

## 🚀 نصب و اجرا

### پیش‌نیاز
- Node.js نسخهٔ ۱۸ یا بالاتر

### مراحل

```bash
git clone https://github.com/YOUR_USERNAME/AtomicHabit.git
cd AtomicHabit
npm install
npm start
```

سپس در مرورگر:

```
http://localhost:4000
```

ثبت‌نام کنید؛ چند عادت نمونه به‌صورت خودکار ساخته می‌شود.

### اسکریپت‌ها

```bash
npm start    # اجرای سرور (پورت پیش‌فرض 4000)
```

پورت دلخواه:

```bash
PORT=3000 npm start
```

## 🔐 متغیرهای محیطی (اختیاری)

| متغیر | توضیح |
|--------|--------|
| `PORT` | پورت سرور (پیش‌فرض `4000`) |
| `SESSION_SECRET` | کلید سشن (در پروداکشن حتماً عوض شود) |
| `GOOGLE_CLIENT_ID` | برای ورود با گوگل |
| `GOOGLE_CLIENT_SECRET` | برای ورود با گوگل |
| `GOOGLE_REDIRECT_URI` | مثلاً `http://localhost:4000/auth/google/callback` |

مثال:

```bash
export SESSION_SECRET="یک-رشته-بلند-تصادفی"
export GOOGLE_CLIENT_ID="..."
export GOOGLE_CLIENT_SECRET="..."
export GOOGLE_REDIRECT_URI="http://localhost:4000/auth/google/callback"
npm start
```

## 🧠 مبانی روانشناسی (خلاصه)

این پروژه برای آموزش ابزار است، نه جایگزین درمان. ایده‌های پیاده‌سازی‌شده:

1. **هویت** — رفتار پایدار وقتی شکل می‌گیرد که با خودپنداره هم‌راستا باشد  
2. **نشانه → روتین → پاداش** — حلقهٔ عادت  
3. **شروع کوچک** — کاهش اصطکاک شروع  
4. **اثر مرکب** — تداوم روزانه و XP/مزرعه  
5. **پاسخ‌گویی اجتماعی** — گروه، دونفره، لیدربورد  

صفحهٔ «اصول رفتاری» داخل اپ همین مفاهیم را جمع کرده است.
